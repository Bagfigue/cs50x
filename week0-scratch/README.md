# Week 0 - Scratch

## Overview

Week 0 introduced the fundamentals of computer science through Scratch, a block-based programming language developed by MIT.

The goal of this week was to learn how programmers think about solving problems before focusing on syntax.


## Key Concepts

- Algorithms
- Abstraction
- Decomposition
- Variables
- Loops
- Conditionals
- Events
- Functions
- Parallelism

## Notes

### Algorithms

An algorithm is a step-by-step set of instructions used to solve a problem.

### Decomposition

Complex problems can be divided into smaller and more manageable parts.

### Abstraction

Abstraction helps focus on what is important while hiding unnecessary details.

### Conditionals

Programs can make decisions using conditions.

Example:

- If the player touches an obstacle, restart the game.
- Otherwise, continue moving.

### Loops

Loops allow instructions to be repeated without duplicating blocks of code.

### Variables

Variables store information that can change during program execution, such as scores, timers, or lives.

## What I Learned

This week reinforced the idea that programming is fundamentally about problem solving rather than memorizing syntax.

Before writing code, it is important to** understand the problem**, break it into smaller pieces, and define a **logical sequence of steps** to reach a solution.

This lesson was particularly important because it revisited concepts that I first encountered at the beginning of my Software Engineering degree, such as algorithms, abstraction, decomposition, variables, and logical reasoning. Reviewing these fundamentals helped strengthen my understanding and provided a solid foundation for the more advanced topics that will be covered throughout the rest of the course.
