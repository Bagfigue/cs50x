# Week 1 - C

## Overview

In Week 1, I could learn more about the C programming language, moving from the visual programming concepts of Scratch to writing code using text-based syntax.

This week focused on understanding how computers process instructions, how programs are structured, and how to solve problems through programming fundamentals. The transition from blocks in Scratch to actual code helped me better understand what happens behind the scenes when a program runs.

## Topics Covered

-Introduction to the C programming language
-Compiling and running programs
-Variables and data types
-Input and output with printf and get\_\* functions
-Arithmetic operators
-Conditional statements (if, else if, else)
-Loops (for and while)
-Functions
-Basic debugging concepts
-Command-line compilation

## Problem Sets and Exercises

### Hello

Basic 'Hello, world' program, just to show how to compile and execute codes.

### Mario

Used loops to generate pyramid patterns, reinforcing repetition structures and logical thinking.

### Cash (or Credit)

Applied conditionals, arithmetic operations, and algorithmic reasoning to solve real-world style problems.
They have also introduced the idea of integer overflow and how to treat it. 

  - **Integer Overflow:** Happens when a number exceeds the maximum value that a data type can store. When this occurs, the value wraps around and produces an incorrect result.

Besides that, they have also mentioned about 'truncation';
  - It occurs when a decimal value is converted to an integer. The fractional part is discarded rather than rounded.
